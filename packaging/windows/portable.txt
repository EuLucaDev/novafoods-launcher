Nova Foods Launcher portable mode

While this file sits next to novafoods-launcher.exe, Nova Foods Launcher keeps its settings, its
download cache and its record of installed apps in the NovaFoodsLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Nova Foods Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Nova Foods Launcher) instead.
If NovaFoodsLauncherData can't be written (for example on a read-only drive), Nova Foods Launcher says
so and uses %APPDATA%\Nova Foods Launcher instead.
